# Mistake Detective evaluation

Generated by `python tools/evaluate_detective.py --write-doc` from [`tests/data/detective_corpus.json`](../tests/data/detective_corpus.json). `tests/test_detective_corpus.py` fails if the guarantees below regress.

> **This is an internal regression benchmark, not a scientific accuracy claim.** The corpus is 230 single-step cases written for this project (most generated from the mathematics and then reviewed against SymPy; the domain set written by hand). It is small, not drawn from real students, and labelled under Pi Core's documented conventions (log = ln, radians, real solutions, other letters constant under d/dx). Relabelled cases carry a `relabel` field explaining why.
